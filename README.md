# DUSTBORNE（Gun-Shooting）

ランダム生成の銃を集めながらウェーブを生き延びる、ブラウザで遊べるトゥーン調FPS。
ソロに加えて、最大5人の協力プレイに対応。

## 起動

```bash
npm install
npm start
```

ブラウザで http://localhost:3000 を開く。Railway などにそのままデプロイできる（`PORT` 環境変数を使う）。

## 協力プレイ

- タイトルの「協力プレイ」→ 名前を入れて「部屋を作る」。表示された4文字のルームコードを仲間に伝える
- 仲間はコードを入れて「参加する」。1〜5人のどの人数でも出撃でき、出撃後の途中参加もできる
- 敵とウェーブは部屋を作った人（ホスト）のブラウザが計算する。ホストが抜けると次の人が自動で引き継ぐ
- 人数が多いほど敵の数と体力が増える
- ドロップと宝箱は一人ひとり別々（取り合いにならない）。経験値は全員に入る
- 倒れた仲間は近づいて E 長押しで起こせる。セカンドウィンド（敵を倒して自力で起き上がる）は1ゲーム1回まで
- 力尽きたら観戦モード（フリーカメラ・仲間からは見えない。左クリックで仲間の視点、右クリックでフリーに戻る）。次のウェーブで拠点から復帰
- 全員が力尽きたらゲームオーバー
- 注意：ホストがタブを最小化・非表示にすると、ブラウザの仕様でゲームの進行が止まる

## 拠点の設備

| 設備 | 内容 |
|---|---|
| 弾薬 / 回復 / 武器 | 弾薬とグレネードの補充、全回復、武器の購入 |
| 改造台 | 持っている武器を強化（レベルアップ、ダメージ・マガジン・連射・リロード・精度のチューン各3段階、属性の付け替え、レア度アップ〜エピック） |
| ガチャ | レア以上が出やすい武器ガチャ |
| タレット | 設置型の自動砲台（X キーで設置・25秒・2台まで所持） |
| 復活 | 倒れたとき自動で起き上がる復活キット（1個まで） |

## 敵

ならず者 / イカレ野郎 / ダストハウンド / 重装ブルート / ボマー / 偵察ドローン / ボス（5ウェーブごと）に加えて

- **狙撃手**：赤いレーザーで狙ってから高威力の一発を撃つ
- **盾持ち**：正面からの弾をほぼ防ぐ。回り込むか爆発で
- **衛生兵**：周りの敵を定期的に回復する
- **自爆魔**：突っ込んで自爆。倒すと爆発して周りの敵を巻き込む

## 構成

- `server.js` … Express + Socket.io。部屋の管理とメッセージの中継のみ
- `public/index.html` … ゲーム本体（Three.js r128）

開発用：URL に `?debug` を付けると `window.__db` からゲームの内部状態を触れる。
